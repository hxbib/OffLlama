- The shipping 0.90 threshold accepted 44/120 decisions, with 41/44 correct.
  The 61/120 comparison uses 0.80, which is not the shipping setting.
- The memory-context diagnostic uses authored and reused calibration rows on CPU.
  It does not measure improved phone task success.
- No general statistical error guarantee is established. No new student is shipping.
- Multi-step app workflows and durable busy/voice/camera admission remain unfinished.
- Voice uploads audio before transcript screening; images may contain recognizable pixels.
  Text masking is incomplete, and selected screened memories can accompany cloud requests.
- Linux CPU and cloud GPU performance must never be labelled as iPhone performance.
