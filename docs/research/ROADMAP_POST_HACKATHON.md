# Pocket Glimmer: 30/60/90-day roadmap after the hackathon

> Nov 4 2026. Each line names its motivating source. Rules carry over: only Meta models ship, selection on calibration data only, a frozen test set, no `trust_remote_code`. Anything that trains or spends credits needs Habib's yes. Sources: LEDGER §12–13, IMPROVEMENT_PLAN_NOV1.md, ARXIV_SCAN_NOV4.md, RELATED_WORK.md.

## Days 0–30: measure on the phone, grow the data the bound rests on
1. **Phone numbers and a parity check.** Log TTFT, tok/s, peak RAM and decision ms on the iPhone 17 Pro. Check that llama.cpp-on-Metal letter probabilities match llama-server on the same 300 gold items, so the cal180 bound carries over to the phone. *Source:* NEXT_AGENT §0; the PocketTSLM numerical-parity protocol (arXiv:2610.21308).
2. **KV prefix cache for the fixed system prompt + few-shot block.** Prefill only the per-request suffix (`llama_state_*` save/restore), then re-measure decision latency. *Source:* IMPROVEMENT_PLAN #3; llama.cpp save-load-state example.
3. **Bigger calibration set (180 → ≥ 600 hand-labeled items, same distribution, test120 untouched).** Certifying the 5% target needs ≥ 135 handled rows with 0 errors, and Mondrian buckets need ~65–135 handled rows each. *Source:* IMPROVEMENT_PLAN "sample-size check"; LTT (arXiv:2110.01052).
4. **Permutation-debiased readout (PriDe-style), selected on cal only.** Average letter distributions over option orders, with a contextual-calibration prior per permutation. Ship it only if the cal bound improves at acceptable latency. *Source:* Zheng et al. ICLR 2024 (arXiv:2309.03882); SCOPE's order-swapped uncertainty (arXiv:2602.13110); `eval/experiments/run_perm_avg.py` (Nov 4).
5. **Audit sampling once online.** Send a small scrubbed share of above-τ decisions to Muse Spark 1.3, fill `agreed_teacher` in telemetry, and alarm when the agreement rate drifts. This checks exchangeability in the field and adds candidate calibration rows (they still need hand labels before they can certify anything). *Source:* hunch's graduate-then-audit loop (github.com/undrgrnd-labs/hunch); our Telemetry table.
6. **Out-of-scope abstention target.** Add the CLINC out-of-scope false-confident rate (shipping 9.2% at τ 0.8, partial N=600) as a tracked metric next to cal180. *Source:* eval/results/OOS_STRESS.md.

## Days 31–60: a better teacher signal, a second distillation round
7. **Higher-precision Glimmer teacher.** Relabel at Q4_K_M/K-Quant-17GB (partial offload on the 3080 Ti, or Modal) instead of IQ2_M, with option-order permutation averaging of the teacher's letter probabilities. *Source:* IMPROVEMENT_PLAN #4; Glimmer model card (K-Quant degradation 0.2–1.0%).
8. **Muse Spark Open as teacher with real logprobs and a KL soft-label loss.** The Baseten run gave only k=8 vote shares, and its student was overconfident (bound 13.7%). Retry through a provider that returns logprobs, mix ½ teacher distribution + ½ gold where gold exists, and select on cal. Ship with "Built with Muse Spark Open". *Source:* SPARK_TEACHER.md; Vela 3.0's soft-target mixing (vllm-sr.ai blog, Oct 26 2026); Hinton et al. 2015; docs/LICENSING.md.
9. **Fix nudgeNow at the data level** (3/10 on test120). Hand-label "later" cases, then use the stronger teacher only for those items. Policy until the bucket has ≥ 65 cal rows: always take its fallback. *Source:* AFTER_FLOOR_NV2.md (teacher agreed on only 20/66 "later").
10. **Telemetry → distillation round 2.** Use exported decision CSVs from real use (opt-in, on-device scrub) as scenario seeds, label them with the teacher, retrain one epoch, then recalibrate τ with LTT. *Source:* README architecture loop; Telemetry.csv().
11. **Mondrian/per-type LTT, only where N allows.** Use one global bound until a type has ≥ 65 handled cal rows, then a per-type τ for that type. *Source:* IMPROVEMENT_PLAN #6 (Vovk Mondrian CP); LEDGER §12.
12. **Instinct-style memory consolidation.** A nightly on-device pass, run while charging, merges duplicates, turns examples into traits, writes dated corrections, and keeps a profile one-pager plus aliases for keyword recall. Every merge is a `memoryConflict` decision gated by τ. *Source:* the Instinct reverse-engineering article (Supermemory founder); OpenClaw "dreaming" (docs.openclaw.ai/concepts/memory); sleep-time compute (arXiv:2504.13171).

## Days 61–90: new modalities, smaller and on-device training
13. **Voice in, via Muse Voice Transcribe** (`muse-voice-transcribe-1.0`, Meta Model API, $0.18/h, online only). Transcripts go through the same scrubber, and offline we fall back to typing. *Source:* docs/PROVIDERS_AND_LICENSES.md.
14. **Camera "glimpses" with SAM 3.1** (`sam-3.1`, Responses API) when online. Offline candidate: a small Meta Perception Encoder (PE-Core, Apache-2.0), fit unmeasured. *Source:* PROVIDERS_AND_LICENSES.md; Perception Encoder (arXiv:2504.13181).
15. **A 2-bit QAT Llama-Reflex-1B** (~0.3–0.4 GB) using ParetoQ code (BSD-3) on Llama 3.2 weights, *not* the FAIR-NC MobileLLM-ParetoQ checkpoints. It must match Q4_K_M on the cal bound, since post-training Q2_K collapsed (bound 30.4%). *Source:* ParetoQ (arXiv:2502.02631; github.com/facebookresearch/ParetoQ); Apple 2-bit QAT (machinelearning.apple.com, 2025); QUANT_IDENTITY.md.
16. **On-device overnight LoRA refresh.** Personalize the Reflex adapter on the phone while charging, then recalibrate before swapping it in. *Source:* "Fine-Tuning a 3B-Parameter LLM on a Smartphone" (arXiv:2610.06325: one charge for a 3B on an iPhone 17 Pro, ~½ throughput under throttling).
17. **Local System 2 when a sub-4 GB Meta model exists.** Today Glimmer's smallest coherent build is 9.85 GB (IQ2_M) and Q1_0 is incoherent, so System 2 stays in the cloud. Re-test any new small Meta model (or a Meta-licensed MoE with llama.cpp support) against the ~5.5 GB budget. *Source:* README "Why not run the 30B"; MobileMoE (arXiv:2605.27358) is the shape we'd want, but it is FAIR-NC today.
18. **Write it up.** A short paper on certified on-phone escalation for typed agent decisions, negative results included. *Source:* NeurIPS 2026 Workshop on On-Device Intelligence (ODI 2026), where CopRoute (arXiv:2610.13276) was accepted. Check the call for papers for 2027.
