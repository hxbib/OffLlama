Built with Llama · every model is Meta's

Four Meta models, four jobs.

Student · on the phone

Llama 3.2 1B → Llama-Reflex-1B

12 typed decisions, Q4_K_M GGUF (808 MB), llama.cpp + Metal. Llama 3.2 Community License.

Teacher · local

Muse Glimmer 30B

Run locally (IQ2_M). Its option-letter probabilities are the soft labels (892 labels). Apache-2.0 open weights.

Escalation · cloud

Muse Spark 1.3

Only when the phone is unsure. Meta Model API, Standard mode only, behind a privacy scrubber.

Evaluated · rejected

Muse Spark Open

As teacher: labels matched gold 178/180, but the 1B it taught was overconfident (cal180 bound 13.7% vs 10.2%).

Meta built Glimmer by logit-distilling Muse Spark (arXiv 2610.24628); we add one more hop, onto the phone:
Muse Spark → Muse Glimmer 30B → Llama-Reflex-1B
System-2 senses (online only, same gate): Muse Voice Transcribe for speech, Muse Spark 1.3 vision and SAM 3.1 for the camera. Each call passes the on-device sensitivity decision, masking and Standard mode. API calls verified live Nov 4; the iOS mic/camera UI is not yet verified on a device.
Sources: README "Meta stack", JUDGE_BRIEF §3, SPARK_TEACHER.md, ARXIV_SCAN_NOV4.md, META_MULTIMODAL.md.7 / 11
Negative results we're proud of

What didn't work, measured and kept.

Glimmer 30B on the phone

1-bit Q1_0 outputs gibberish. The smallest coherent quant, IQ2_M, is a 9.85 GB file.

Llama 3.2 3B on the phone

5.03 GB peak RSS (box CPU): only ~0.47 GB under our ~5.5 GB budget. The 1B runs; Glimmer teaches.

2 epochs

More confident, not more correct: accuracy on kept 0.96 → 0.90, bound 10.2% → 14.2%.

Other teachers lost on cal180

nudge relabel (nv2): bound 10.9%. Muse Spark Open teacher: 13.7%. Shipping Glimmer student: 10.2%.

Quant ladder

f16 14.5%, Q8_0 13.9%, Q3_K_M 13.9%, Q2_K 30.4%. Nothing beat Q4_K_M on cal180.

Option-order averaging

Ranks better, but under-confident: ECE 0.072–0.101 vs ≤0.056, at 2–3× latency. Did not ship.

Round 2 (Nov 4): see eval/results/ROUND2.md · same cal180 gate; the shipping model changes only if a variant wins.
