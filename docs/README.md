## Folders

- [`verification/`](verification/) holds build, install and review records, with raw test logs.
- [`training/`](training/) and [`research/`](research/) hold training runs, candidate experiments and research notes, including rejected ones.
- [`process/`](process/) holds the build-week ledgers, agent handoffs and final-hours checklists. They are historical working notes.
- [`archive/`](archive/) holds superseded drafts from the earlier Pocket Glimmer design. Their claims are not current.
